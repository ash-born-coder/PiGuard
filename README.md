### Milestone 02 — System Preparation ✅

After setting up Raspberry Pi OS and SSH, I focused on preparing the Pi Zero W for running Pi-hole.

I updated the system, checked storage and memory usage, and tested internet connectivity and DNS resolution. I also inspected the network configuration to prepare for assigning a stable IP address.

This stage helped me become more familiar with Linux commands and troubleshooting SSH connections.
